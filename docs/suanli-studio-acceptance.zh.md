# 媒体工作室自测与验收计划

[English](suanli-studio-acceptance.md) | 中文

## 摘要

本清单供[画布工作室](suanli-canvas-studio-spec.md)的开发者和发布验收人员使用，区分日常自测、正式应用验收与后续待测。合入代码不代表待测项已通过。

已有自动回归及 Windows VM 中使用本机短素材的正式原生应用证据，覆盖导入、候选与采用分离、本地音视频操作、四轨编辑、完整质量缓存、播放、下载与导出一致、局部返工、响应式布局及卡片摘要。这些证据不代表付费云端生成、真实 GPU 性能、长片可靠性已通过，也不代表间歇性 Vpx 解码错误的根因已修复。

## 开发者自测

在仓库根目录按[开发环境要求](development.zh.md)准备环境。按改动运行最小相关集合；源码和输入未变时复用有效结果。下列命令指向现有测试归属，不能替代[测试政策](testing.zh.md)或 CI 覆盖率检查。

| 改动范围 | 自测 | 必须确认 |
|---|---|---|
| 时间线、版本、持久化 | 下方命令中的 Canvas 测试 | 版本冲突保留草稿、原子保存、不透明版本标识可往返、创建候选不改变采用、固定引用的素材不被删除。 |
| 合成与媒体任务 | Tool-media 与合成器测试 | 画面与声音时序、字幕合成、缓存失效与复用、取消、迟到结果及重启恢复。 |
| 本地处理 | 本地 FFmpeg 测试 | 实际时长、音量、淡入淡出和尾帧；缺少 FFmpeg 时标为未测。 |
| 界面、Remote 与文件传输 | GUI 测试及桌面转发测试 | 草稿与冲突恢复、范围隔离、Range 206/416、文件长度、取消、鉴权及仅所有者可访问的接口。 |
| agent（智能体）可见操作 | 无密钥的会话录制回放 | 使用正式配置及工具注册表；持久化结果匹配；局部返工保留其他片段和文档。 |
| 构建与文档 | 先构建产物，再做聚合检查；文档与 lint 检查 | 实际运行路径及 Host/Client 类型通过；双语文档与生成引用同步。 |

```sh
pnpm exec vitest run packages/media/canvas/tests packages/media/tool-media/tests packages/util/timeline-compositor/tests
pnpm exec vitest run packages/media/tool-media/tests/local-edit.ffmpeg.spec.ts
pnpm exec vitest run packages/client/ui-sidebar-canvas/tests
pnpm exec vitest run apps/desktop/tests/web-document.spec.ts packages/experimental/liveshare/tests/endpoint-classification.spec.ts
pnpm run test:snapshot snapshots/session/headless.snapshot.ts -t 'timeline-editing|canvas-media-adoption|canvas-local-edit|canvas-editor-context'
pnpm run build:artifacts
pnpm run build:check
pnpm run test:docs
pnpm run doc-sync
pnpm run lint
```

无密钥回放前，在调用命令的 shell 中设置 `DSH_SNAPSHOT=replay` 并移除真实模型凭据。核对筛选器实际选中的场景；跳过不算通过。界面变更后运行对应 Web 回放；[Web 测试层级](testing.zh.md)负责完整浏览器覆盖。焦点测试通过不等于 Web 全量通过。

本地任务不得新增 Agent 轮次、模型或上下文请求、完成通知、会话日志投递。测试保持默认唤醒策略，不能通过关闭唤醒掩盖问题。任务生命周期变化后，既有结果不能代替相关回归。

## 正式原生应用验收

使用当前正式构建、Electron Main/Host 及正式 `dsh` 配置。使用可丢弃的测试项目和已有本机音视频，记录机器、系统、Electron／编解码能力与构建标识。独立原型、隐藏 RPC 写入、改项目 JSON 或伪造 DOM 状态不能作为原生验收。

仅做本地测试时，先核对实际生效的文本路由指向请求拦截器、会话日志投递关闭、正常唤醒策略仍生效。记录拦截器与 Session 计数。测试前保存项目／时间线字节、节点／轨道／片段／版本标识、源偏移、时长、采用版本及冻结的剧本／设定集／分镜文档。

| 步骤 | 界面操作 | 验收条件 |
|---|---|---|
| 1. 导入与试听 | 导入两段视频及本机音乐／语音，试听候选并重试预览。 | 创建／试听候选不改变采用；重试不生成、不重复导入；本地操作的模型与通知计数保持零。 |
| 2. 四轨编辑 | 使用视频、语音、音乐、字幕轨，调整裁剪、音量、淡入淡出、字幕样式与转场。 | 保存重开后标识、源偏移及参数完全保持；撤销／重做可持久恢复；候选与采用仍分离。 |
| 3. 缓存与导出 | 生成完整质量缓存，自然播放到结尾，双向跳转并导出、下载。 | 同一版本／设置的预览、导出和下载 MP4 哈希相同；独立探测确认时长、尺寸、帧率与声音。本机八秒基线为 720×1280、24fps、H.264/AAC、48kHz 立体声。 |
| 4. 局部返工 | 在编辑器修改一个片段，再通过 Agent 回放执行等价操作。 | 仅受影响的缓存部分重做；其他片段、手动参数、固定引用、音乐／字幕及冻结文档不变；预览明确对应当前版本。 |
| 5. 响应式可达性 | 检查 390、760/761、1100/1101、1600px 宽度，矮窗／高窗、粗指针、滚轮、真实触控与键盘。 | 四轨及主要操作可达；44px 片段与 28px 轨道按钮可完整露出；长参数可双向滚动；焦点可见；没有页面级横滚、重叠或裁切。 |
| 6. 关闭与重载 | 打开时间线、关闭、重开并重载当前数据。 | 片段数／时长来自可信旁文件；五片段八秒基线卡片显示 5／8.0秒。未读取时显示打开编辑器入口；旧导出元数据不能制造假零或旧摘要。 |

结束后恢复临时网络拦截和指针覆盖。临时草稿通过正式“丢弃”操作清除。清理后重读持久化文件及计数；不应变化的文件必须字节一致。每次连续执行保留一份工具登记的录屏，配合断言及独立媒体／文件核对。

## 后续待测项目

宣称对应发布能力前需完成下表。短素材本机基线不能关闭这些项目。优先验证范围／数据保护和模型误调用，再验证恢复、真实云端路由及支持设备的性能。

| 编号 | 待测内容与起点 | 通过条件 | 证据 |
|---|---|---|---|
| N1 | 原生 390/761px 长驻加载；仅延迟本次拥有的本机读取，再解除。 | 加载文案可读；不安全操作禁用；滚动、焦点、重试及恢复可达；无跨项目写入。已有快速重载观测不能证明长驻转圈布局。 | 录屏、真实加载／禁用状态转换与清理证明。 |
| N2 | 两个项目／分集含相同节点标识；打开 A 后切 B，延迟／阻断 A 的读取，再返回恢复。 | B 不出现 A 的摘要／草稿／素材；不可信／不可用数据不显示旧计数；无旧保存、迟到写入或草稿丢失。当前范围／可信状态断言有组件覆盖，尚无原生切换证据。 | 原生录屏、带范围的读写轨迹与前后文件。 |
| N3 | 用原容器／编码及候选切换路径复现间歇性 Vpx 错误；测首次播放、重试与重启。 | 捕获实际错误及传输／编码事实；恢复不重生成、不改采用。后续播放成功不能单独关闭根因问题；持续失败保持可见。 | 错误日志、编码探测、Range／长度响应、最小复现及恢复录屏。 |
| N4 | 中断／取消完整质量渲染，断开渲染端，重启 Main/Host 并接收迟到结果。 | 无重复提交、悬挂租约或被标成就绪的半成品 MP4；取消后任务收敛；迟到结果不替换其他版本；恢复状态明确且引用保留。 | 任务／状态轨迹、重启录屏与输出／缓存哈希。 |
| N5 | 真实 Windows/macOS 设备，硬件加速开／关，使用 H3 HEVC/H.264 素材。 | 不支持的解码进入约定兼容路径；成片可有声播放／跳转；无静默编码失败及画幅／颜色／方向错误。 | 设备／驱动／编码清单、兼容结果与独立导出探测。 |
| N6 | 正式原生项目，60秒、5分钟、15分钟，1080 与 1440×2560 输出，多条视频／音频／字幕轨。 | 测前约定完成耗时、内存／磁盘峰值及并发预算，再按预算实测。完整质量缓存播放流畅且音画同步；取消／重启及局部返工不损坏数据。不要求实时高分辨率合成。 | 时长／帧／声音检查、丢帧、资源峰值及渲染／返工耗时。 |
| N7 | 在支持的 CI 平台运行只读 Web 全量回放，包含设置及文档预览归属。 | 所有必需用例通过；独立归因定位器歧义或平台基线差异。不能仅改期望来掩盖失败，焦点通过不能代替全量。 | 完整命令、选中数量、失败处理结论与 CI 产物。 |

## 云端模型验收

这些项目需要获准的付费生成预算，以及真实 MAAS 目录／权限。本机测试授权不包含云端提交。先确认实际网关契约及模型可用性；未开放能力保持不可用，不能把上游模型能力当作 MAAS 已开放能力。

| 模型／路径 | 测试 | 验收条件 |
|---|---|---|
| H3 加聚合超分 | 在 H3 支持的单镜时长内生成原生 768P，按开放能力加入对白及参考音色；更高分辨率走聚合路由。 | 仅一次有意生成流程；查询／重连不重交；探测实际交付尺寸，不以模型名的 2K 标签代替；保留源／结果版本及声明用量。 |
| YuE2 | 生成并保留返回乐谱；按实际能力修改歌词、风格、旋律／和弦；通过面板及 Agent 比较版本。 | 乐谱与已开放参数重启后可复用；新候选不自动采用；请求／返回字段符合真实网关。 |
| ACE-Step | 文本／纯音乐生成、参考音频改编、力度与区间重绘。 | 参考与区间参数正确传递；仅指定源区间在约定声音容差内改变；区间外时长／内容及时间线固定版本受保护。 |
| MiniMax Music3 | 歌词／风格生成、试听及第二个候选。 | 参数、可播放结果、任务恢复及明确采用均通过面板／Agent 共用操作层完成。 |
| Breeze 2 | 网关开放的音色描述、表达／情绪及语速控制。 | 真实音频符合已开放指令；未开放的参考克隆不伪装为可用；原文本与参数可继续编辑。 |
| IndexTTS／MOSS | 已开放的参考音色或描述音色旁白路径。 | 参考与文本正确；音频可播放并保存版本；没有未开放的音色库、续写、去噪及转写入口。 |
| 每条启用路由 | 超时、取消、服务商失败、客户端断线与应用重启。 | 查询同一远程任务而非重复计费；错误可操作；迟到结果留在原项目；不跨项目挂回、不意外采用。 |

还需验证创作者整条流程：只补问缺失的时长、画幅、分辨率及真人／动画选项；生成前给方案，在授权范围内完成，随后请用户审核并仅返工受影响部分。记录真实请求、远程任务标识、实测输出及用量，不保存凭据或原始私密日志。

## 完成条件与证据

每项记录构建／引用、日期、执行人、机器、起始项目／版本、命令或实际界面动作、观测结果、独立文件／媒体核对、录屏及清理。标明通过、失败、阻塞或未测，并写出缺少的前提。模拟结果、跳过用例、瞬间加载态或成功重试不能替代另一个缺失场景。

本地可用需满足自测、原生基线、不相关数据完整保留及无意外 Agent／模型活动。宣称某云端路由可用需通过该路由真实验收；宣称设备／长片支持需通过 N5/N6。未明解码根因及缺失平台证据保持公开。数据损坏、范围泄漏、意外付费提交、采用版本被改变或预览／导出不一致，任一项即验收失败。
