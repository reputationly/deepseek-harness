# 画布媒体任务与恢复

[English](guide.md) | 中文

## 变更

画布、项目、设定集和制作状态写入前都会完整校验；拒绝写入会保留文件字节和 revision。与本条目名称或别名重复的别名按大小写无关规则去重；跨条目重名会被拒绝。已有非法文件需显式修复。

Canvas Session 中的四个 `generate_*` 工具会在提交前建节点，并与 `canvas_generate` 共用 Host 任务、校验和持久挂载。自定义组合需要任务服务和控制器。纯文件组合保留独立生成。视觉生成要求设定集非空，包括没有 `@` 的提示词。成功表示版本已挂载。

任务记录保存在 `.canvas/<episode-file>.media/`。打开画布时会挂载已完成的文件，或继续查询已知远端任务，不会重新提交。网关直接以 HTTP 错误应答的提交表示未被接受：5xx 仍可重试，4xx 不可重试，均不设置 `recoveryRequired`。网关接受提交后的失败与提交结果未知的任务需要先核实供应商历史记录，再发起新的付费请求。本地取消不表示供应商已经取消。仍有这些记录时降级会丢失上述保护。

所有者或 Host 退出时会保留已知远端任务和已有文件，供后续恢复。显式取消保持终止。已有 `cancelled` 检查点也保持终止，因为旧记录不含取消来源；人工处理前需核实供应商历史。自定义 jobs provider 必须将 `kill` 或 `teardown` 作为第二个参数传给 `JobHooks.cancel`。

画布文档和媒体任务记录使用共享的原子写入，对 Windows 文件共享错误执行有界重试。重试时如需恢复保留的任务，会等待该任务，不会在同次操作中为同一节点重新提交生成。

`tool-media` 要求运行在 Host 本地的 `subprocess` 提供方。卸载时会拒绝新请求，等待完整进程树退出，并等待预览缓存清理完成。

## 迁移

1. 自定义组合需要 `@deepseek-ai/dsh-subprocess-local`；画布生成还需要 `@deepseek-ai/dsh-jobs-local` 和 `@deepseek-ai/dsh-tool-jobs`。内置桌面组合已包含这些提供方。
2. 视觉生成前先填写项目设定集。遇到预算确认拒绝时，先向用户展示总量，取得同意后，将返回的节点 id 和令牌传给 `canvas_generate`。
3. 备份 `.canvas/` 和 `outputDir`，恢复完成前保留检查点。远端查询需要原网关配置。已完成文件无需向供应商提交。解除 `recoveryRequired` 前先核实供应商历史；修改提示词不会清除此标记。
4. 打开画布，确认恢复结果成为活动版本，节点不再停留在排队或运行状态。降级前先处理活动任务。视频解码失败或只有音轨可播而没有视频帧时，会使用 `.canvas/previews/` 下的本地兼容预览。这些缓存可用 FFmpeg 重建；原始媒体保持不变。
5. 在 Host `tool-media` 实例上配置网关、凭据和确认阈值；画布 UI 使用其 `media` Remote 命名空间。桌面启动会重新生成 `cordis.patch.yml`，因此应修改部署的配置来源并重启，核实 Agent 和 UI 两条路由。受控测试必须使用无法授权生产供应商的凭据。
