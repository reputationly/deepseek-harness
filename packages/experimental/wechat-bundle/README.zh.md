# @deepseek-ai/dsh-wechat-bundle

[English](README.md) | 中文

## 摘要

实验性微信 ClawBot 组合包通过腾讯 iLink 将微信私聊连接到本机 DSH 智能体。在「设置 → 微信」中绑定后，即可直接向 ClawBot 发消息。选定的 DSH 工作区和对话会保存在本机，并可在桌面应用中继续查看和使用。

此组合包包含 Host 集成和 Client 设置卡片，不支持群聊。

## 使用此组合包

在插件管理器中安装或启用「微信 ClawBot」。打开「设置 → 微信」，选择「添加微信」，然后使用拥有该私聊的微信账号扫描二维码。

使用微信时请保持桌面应用打开，并避免电脑进入睡眠。发送 `/help` 可查看可用命令。

## 已知限制和延后工作

- 此集成功能处于实验阶段，可用性和协议行为取决于腾讯 iLink。
- 只处理已绑定所有者账号的私聊消息；群聊消息会被忽略。
- 本机 Host 必须保持运行才能接收消息。
