# 画布布局

画布是用户的工作台，位置有含义。按下面的顺序从左到右排：

1. 设定参考图（角色、场景、道具）
2. 剧本
3. 分镜表
4. 图片
5. 视频
6. 配音
7. 成片

## 组

- 一场一个组：组里放这一场的文本节点和分镜表，视频节点也放进同一个组。
- 组名写场号：`场2 便利店`。铺开剧本时用同名组判断"这一场已经铺过"，避免重复建。
- 组不嵌套。

## 批量建节点之后

- 新建的节点由画布自动摆放：默认放在上游节点的右边。批量铺开剧本后如果重叠，调用一次 `canvas_edit` 的 `move` 把整组挪开，不要逐个微调。
- 用户手动拖过的节点（`placed`）不会被自动布局移动；改布局时不要动它们。
- 节点标题写用途，不写 id：`场2 分镜`、`林夏 三视图`、`场2 段1`。
