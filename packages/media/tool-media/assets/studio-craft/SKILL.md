# 剧本、分镜与提示词

## 剧本

- 每场一行标题：`【场1】场景名`。标题下面写这一场的内容，一段一行，不写镜头术语。
- 一集 3–6 场。开头 3 秒给出钩子（异常、冲突、反差），结尾留一个问题。
- 场次编号连续，不跳号；改写时保留编号，只改正文，这样已经铺开的分镜不会全部作废。

## 分镜表

一张分镜表属于一场。每个镜头写全七要素，缺一个都会被闸门挡住：

1. **景别**（`shotSize`）：`extreme_wide` / `wide` / `full` / `medium` / `medium_close` / `close` / `extreme_close` / `insert`。
2. **画面**（`visual`）：这一帧看得见什么，不写"他很伤心"，写"他低头盯着湿透的鞋"。
3. **动作**（`motion`）：人物在这一镜里做什么。
4. **运镜**（`camera`）：推、拉、摇、移、固定；没有特殊运镜写"固定"。
5. **时长**（`durationSec`）：1–15 秒；一般镜头 2–5 秒。
6. **台词**（`dialogue`）：每句写说话人（角色 id 或旁白）和台词原文。
7. **音效**（`sfx`）：环境声或动作声；没有就留空。

负向词（`negative`）写这一镜不要出现的东西：多余的手指、文字水印、镜头抖动。

## 提示词

- 图：主体 + 外观 + 环境 + 光线 + 质感 + 画幅。主体用设定集的名字（`@林夏`），不要每次重新描述角色长相。
- 视频：在图的提示词后加"动作 + 运镜 + 时长"；不要写对白，对白由配音节点承担。
- 角色一致性靠三样：设定集里的描述句、主参考图、`@名字` 引用。三者一致，生成结果才稳定。
- 一个镜头只讲一件事。要换场景就新开一镜。

## 改写

改分镜时用镜头 id 定位（`update_shot` 的 `shot`），不要整表重写。整表重写会让所有已生成的视频节点变成"分镜已改"。
