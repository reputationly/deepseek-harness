# 剧本、分镜与提示词

## 剧本

- 每场一行标题：`【场1】场景名`。标题下面写这一场的内容，一段一行，不写镜头术语。
- 一集 3–6 场。开头 3 秒给出钩子（异常、冲突、反差），结尾留一个问题。
- 场次编号连续，不跳号；改写时保留编号，只改正文，这样已经铺开的分镜不会全部作废。

## 分镜表

一张分镜表属于一场。每个镜头写全七要素，缺一个都会被闸门挡住：

1. **景别**（`shotSize`）：`extreme_wide` / `wide` / `full` / `medium` / `medium_close` / `close` / `extreme_close` / `insert`。
2. **画面**（`visual`）：这一帧看得见什么，不写"他很伤心"，写"他低头盯着湿透的鞋"。
3. **动作**（`motion`）：人物在这一镜里做什么。
4. **运镜**（`camera`）：推、拉、摇、移、固定；没有特殊运镜写"固定"。
5. **时长**（`durationSec`）：1–15 秒；一般镜头 2–5 秒。
6. **台词**（`dialogue`）：每句写说话人（角色 id 或旁白）和台词原文。
7. **音效**（`sfx`）：环境声或动作声；没有就留空。

负向词（`negative`）写这一镜不要出现的东西：多余的手指、文字水印、镜头抖动。

## 提示词

- 图：主体 + 外观 + 环境 + 光线 + 质感 + 画幅。主体用设定集的名字（`@林夏`），不要每次重新描述角色长相。
- 视频：在画面描述后加动作、运镜、时长和声音要求。H3 对白镜头写入分镜中准确的说话人及台词原文；独立旁白或画外音才单独生成 TTS。已有分镜台词沿用，不为了适配模型整表重写。
- 角色一致性靠三样：设定集里的描述句、主参考图、`@名字` 引用。三者一致，生成结果才稳定。
- 一个镜头只讲一件事。要换场景就新开一镜。

## 改写

改分镜时用镜头 id 定位（`update_shot` 的 `shot`），不要整表重写。整表重写会让所有已生成的视频节点变成"分镜已改"。

## 音乐和语音

- 先读当前 key 的实际能力目录，再选模型和参数；不能因为上游开源项目支持就假定网关也提供。保存每版歌词、风格、seed 和实际返回的乐谱，seed 为 0 也要保留。
- **YuE2**：风格放 `gen.prompt`，歌词放 `params.lyrics`；创作规划 `cot` 支持 `full` / `melody` / `off`，谱面用 `params.abc`。用户改旋律、和弦、歌词或风格时复用所选版本的实际 ABC，再生成候选；没有返回乐谱就如实说明，不伪造。
- **ACE-Step**：基础 `t2m`、参考音频 `cover`、区间重绘 `repaint` 只在目录声明该模式时使用。保留歌词、BPM、调性、seed；纯音乐用 `is_instrumental`。改编力度是 `audio_cover_strength`；重绘用秒单位的 `repainting_start` / `repainting_end`，终点大于起点，参考音频来自明确素材。不能把这些秒参数当成本地剪辑的毫秒。
- **MiniMax Music3**：保留为带歌词歌曲路线，歌词和风格说明都需要，不强行把它当作音频局部重绘模型。
- **Breeze TTS 2**：朗读文本放 `gen.prompt`，音色设计与情绪、语速、表达描述放 `params.instructions`，保留 seed。表达标签按已支持格式保留；当前网关只开放音色设计时，不能承诺声音克隆。需要参考录音的 IndexTTS 仅在目录提供且素材已明确时使用。
- 音乐、语音面板与 Agent 修改同一音频节点。试听与采用分开；本地裁剪、音量、淡入淡出优先 `media_edit`，不为不需要重生成的变化再次付费。
