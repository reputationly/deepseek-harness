# 创作画布的总流程

画布是用户和你共用的同一份数据。用户随时可能手动改过它，所以每次动手前先读。

## 每次开始

1. 读画布：`canvas_get` 拿到 `revision`、节点、边和当前分集；需要设定集或项目信息时带上 `include: ['project', 'bible']`。
2. 读已有 `project.json`，沿用它的分集、画幅和品类（`drama` / `comic` / `mv`）。仅在完整制作需要而项目尚不存在时创建。独立歌曲、旁白或单个素材加工不必经过全套剧本流程。
3. 沿用现有剧本、设定集、分镜文档及其 id，不迁移重建或整份重写。新制作先有角色、场景、道具设定，再生成参考图；分镜引用必须存在。用户要求改已有内容时仅定点修改。

## 少问并连续推进

- 从请求和现有项目推断风格与默认值，只集中补问会影响交付的缺项：时长、宽高比、分辨率。已回答的不重问，不让用户填写完整模型参数表。
- 完整成片开始前给两到三个简短方案，说明内容、风格、镜头数、交付尺寸与预计生成用量。用户选定后在该范围内推进；模型目录的实际能力仍然有效。
- 批量视频先做一镜供用户审核，沿用已审定的风格后继续。完成后交付可播放的完整质量预览，请用户指出需要改的部分，不逐节点索要确认。
- 简单的一句话歌曲或旁白任务，采用一次生成的简明方案和合理默认值。
- 视频对白默认走 H3，台词写入视频提示词。H3 原生按 768p 处理；高分辨率优先使用目录中实际提供的生成加超分聚合能力，交付尺寸以实际返回结果为准，不仅凭模型名承诺 2K。
- TTS 用于旁白、画外音或用户明确选择的独立配音。H3 参考音频只影响音色与表达，不保证逐字照念或精确对口型。云端目录没有的功能不提供入口、不伪造调用。

## 动手时的规矩

- **先查后建**：建节点前先 `canvas_get`，已有同名或同用途的节点就改它，不要删了重建。用户的版本历史只在你改同一个节点时才保留。
- **共用写入**：用 `canvas_edit`、`timeline_edit` 和媒体工具修改项目，不直接改底层 JSON。携带读取到的 revision、directory、episode；发生结构化冲突就重读并合并本次差异，不按错误文案猜测结果、不盲重试。
- **分镜是源头**：视频从分镜的镜头来，不手写镜头。改镜头用 `update_shot` / `insert_shot` / `move_shot`，一次调用只产生一个版本。
- **分镜视频走 `canvas_generate`**：对一个或多个分镜一次调用 `canvas_generate`，工具先为每段生成分镜图（keyframe），再批量生成各段视频，场与场并行。不要用 `generate_video` 逐段手写镜头逐个生成；要重做某一镜，重生成它的分镜图或段视频节点即可。
- **候选不等于采用**：生成、上传、本地编辑、导出都先作为候选保存；预览候选或把精确候选版本放入时间线不等于采用。只有用户明确选定时才 `set_version`，不得自动替换旧采用版本。复查手动修改，不凭旧对话覆盖项目。
- **删除前确认**：删节点、删设定条目、删镜头都要先说明删什么、会影响哪些下游节点，得到用户同意再动手。
- **阶段记录**：沿用 `studio_stage` 记录实际进度，方案授权范围内不为例行阶段反复问询。未经过成片审核不能声称已交付；不为绕过缺失产物虚构 `override.reason`。

## 完成与局部返工

1. 用 `timeline_get` / `timeline_edit` 编排视频、原声、独立配音、音乐、字幕，固定每个素材的 node/version，不使用“最新版本”别名。具体操作先读 `media-editing`。
2. 字幕文字取剧本。独立配音按实际音频时长与时间线位置计时；H3 内嵌台词无法仅凭总时长得到逐句时间，只能先做待审核的时间草稿并允许手调，不声称已精确对齐，不调用不存在的云转写。
3. `timeline_render` 后检查 `timeline_render_status`，只有当前 revision 的 `ready` 才是完成预览。编辑后等待受影响片段的完整质量缓存；`timeline_export` 导出同一套合成结果，不另做一个效果不同的 FFmpeg 成片。
4. 用户修改时重新读项目，以准确节点、镜头、素材版本或片段定位。仅修改相关字段；有新的候选素材时保留原采用版本和旧时间线引用，明确更新需要变更的片段，再重建失效缓存。其余镜头、音乐及手改保留。
5. 付费任务结果未知时先查询或恢复，不重复提交。完成文件挂载失败时报告保留路径和恢复动作；本地编辑可显式重试，不能把本地失败送入付费生成重试。

## 一集一个会话

一集用一个会话推进；换集用 `studio_episode_use`，不要在一个会话里同时改两集。新集用 `studio_episode_create`，它有自己的画布文件。

## 停下来问用户的时候

- 要删除或覆盖已有内容；
- 模型或参数不支持当前的输入组合（`needs_choice`）；
- 分镜里缺景别、时长，或引用不存在的设定条目（`blocked`）。
